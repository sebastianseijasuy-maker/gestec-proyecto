# GesTec – Sistema de Gestión de Recursos Tecnológicos

GesTec es un sistema destinado a la gestión de recursos tecnológicos en instituciones educativas, permitiendo administrar inventario, préstamos, devoluciones, incidencias, mantenimientos y disponibilidad de los recursos.
